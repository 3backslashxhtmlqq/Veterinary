# Telegram-бот для учета услуг ветеринарной клиники

## Описание проекта

Данный проект представляет собой Telegram-бота, разработанного на языке C#, предназначенного для автоматизации учета услуг ветеринарной клиники.

Бот реализует систему регистрации, авторизации и разграничения ролей пользователей (Клиент, Врач, Администратор), а также позволяет:
 • управлять карточками питомцев;
 • записываться на прием;
 • управлять услугами клиники;
 • вести учет обращений;
 • подтверждать роли пользователей через администратора.

Проект создан в учебных целях и демонстрирует работу с:
 • Telegram Bot API;
 • файловым хранением данных;
 • разграничением прав доступа;
 • модульной архитектурой.

⸻

## Используемые технологии
 • Язык программирования: C#
 • Платформа: .NET
 • Telegram Bot API
 • Файловая система (формат хранения данных: .txt)

⸻

# Логика работы системы

## Регистрация

Пользователь:
 • вводит команду /register или нажимает кнопку «Регистрация»;
 • вводит свое ФИО.

Создается временный файл в папке: data/temp_users

Формат файла:

ФИО: Иванов Иван Иванович
Роль: Не подтверждена
Дата регистрации: 13.02.2026
Количество записей: 0
Услуги: Нет
Карточки питомцев: 0

После регистрации пользователю предлагается авторизоваться.

⸻

# Авторизация

## Пользователь:
 • вводит команду /login;
 • повторно вводит ФИО.

Далее:
 • Администратору отправляется запрос на подтверждение;
 • После подтверждения файл переносится в папку: data/clients
 • Временный файл удаляется.

⸻

# Повышение до врача

## Для перехода в роль врача:
 1. Пользователь вводит пароль.
 2. Пароль проверяется из файла: data/password/password.txt
 3. Отправляется запрос администратору.
 4. После подтверждения создается файл в: data/doctors

⸻

# Профиль

## Команда: /profile
Пользователь получает информацию из своего текстового файла (clients или doctors).

⸻

# Питомцы
Команда: /pets

Клиент может:
 • добавить карточку питомца;
 • редактировать карточку;
 • удалить карточку.

Карточки хранятся в: data/pets

Формат файла питомца:

Владелец: userId
Имя: Барсик
Тип: Кот
Возраст: 3
Вес: 5
Рост: 30
Порода: Сиамский


⸻

# Запись на прием
Команда: /zapis

Клиент:
 • создает запись;
 • ожидает подтверждения врача.

Файл записи хранится в: data/appointments

Формат:

Клиент: userId
Питомец: Барсик
Описание: Жалоба
Статус: Ожидает
Дата: 13.02.2026

Врач может:
 • подтвердить запись;
 • изменить статус;
 • отменить запись;
 • просматривать историю;
 • выполнять поиск и фильтрацию.

⸻

# Услуги
Команда: /services

Клиент:
 • может просматривать список услуг.

Администратор:
 • добавляет услуги;
 • редактирует;
 • удаляет.

Файл услуг: data/services/services.txt

⸻

# Выход из аккаунта
Команда: /logout

Пользователь завершает текущую сессию.

⸻

# Хранение данных

Все данные хранятся в текстовых файлах формата .txt.

Преимущества:
 • простота реализации;
 • прозрачность структуры;
 • удобство для учебного проекта.

⸻

# Разграничение доступа

Перед выполнением любой операции система проверяет:
 • является ли пользователь клиентом;
 • является ли врачом;
 • является ли администратором.

Если прав недостаточно — операция блокируется.

⸻

# Запуск проекта
 1. Установить .NET SDK.
 2. Вставить токен Telegram-бота в Program.cs.
 3. Создать необходимые папки в директории data.
 4. Добавить администратора в папку data/admins.
 5. Запустить проект.
